## 1. Starting from Zero

- Local operations (rewriting rules) as the mechanism of change

## 2. The Single Minimal Rule — Rule #1.5

**Basic Objects**:
- Indistinguishable nodes
- Only 3-ary hyperedges, each carrying a cyclic phase φ ∈ {0, 1, 2}

**Rewriting Rule**:
For every hyperedge (A, B, C; φ):
- Compute the local phase imbalance δ = (sum of incident phases) mod 3
- If δ ≡ 0 → Cyclic phase rotation (A → B → C)
- If δ ≢ 0 → Diffusion: introduce one new node D and form three new hyperedges (A,B,D), (B,C,D), (C,A,D) with phases minimizing the new δ

**Multiway Dynamics**:
All compatible rewrites happen simultaneously. Physical reality is the set of branches that **maximize long-term stable neutral clusters** (δ ≡ 0).
