## 2. Rule #1.5

**Objects**: Nodes and 3-ary hyperedges with phase φ ∈ {0,1,2}.

**Rule**: 
- Compute local phase imbalance δ mod 3.
- If δ = 0 → cyclic phase rotation.
- If δ ≠ 0 → diffusion (add new node and three new hyperedges minimizing imbalance).

**Evolution**: Multiway system with selection favoring branches that maximize long-term neutral clusters (δ = 0).
